# 🧠 MatrixBD2

Um sistema inspirado no universo do filme *Matrix*, simulando a gestão da realidade virtual controlada por inteligências artificiais. Este projeto propõe a modelagem de um banco de dados relacional completo com suporte a relacionamentos complexos, integridade referencial, visões, índices, procedures, triggers e transações, tudo conectado a uma aplicação web com Express e EJS.

---

## 🎬 Sinopse do Projeto

> Em um mundo dominado por máquinas, a simulação da realidade exige um banco de dados robusto. Este sistema representa a infraestrutura que a IA dominante utilizaria para gerenciar aspectos simulados da realidade, como humanos, eventos, estruturas, agentes e suas interações.

---

## 🚀 Tecnologias Utilizadas

Este projeto integra uma stack voltada à construção de aplicações web com banco de dados relacional:

- **Node.js** – Plataforma backend em JavaScript
- **Express.js** – Framework para criação de servidores HTTP
- **EJS** – Template engine para gerar HTML dinâmico
- **PostgreSQL (PLpgSQL)** – Banco de dados relacional usado na modelagem
- **CSS** – Estilização das páginas web
- **JavaScript** – Lógica de front-end e back-end
- **dotenv** – Variáveis de ambiente
- **pg / pg-format** – Manipulação de queries PostgreSQL
- **express-session / body-parser / cors** – Middleware úteis para rotas e sessões
- **argon2** – Hash de senhas
- **multer** – Upload de arquivos

📊 Linguagens no projeto:

- **EJS**: 57.9%
- **JavaScript**: 15.3%
- **PLpgSQL**: 14.8%
- **CSS**: 12.0%

## 🖥️ Como rodar localmente

Está totalmente documentado no relatório do projeto (PDF), incluindo:

- Instalação do Node.js
- Criação do banco `BD2Matrix` via *PgAdmin*
- Configuração do arquivo `.env` com a senha do Postgres
- Instalação das dependências com `npm install`
- Execução do servidor com `npm run dev`
